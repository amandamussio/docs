# 🧪 Dados para Testes

Este guia apresenta **dados fictícios** que podem ser utilizados para testar integrações com a **Wincred** em ambiente de homologação.

---

## 📋 CPFs para Testes

Você pode utilizar o(s) CPF(s) abaixo para simular fluxos de contratação e validação:

`82611830096`


---

## 💡 Recomendações

- Prefira **empréstimos de valores pequenos** durante os testes.  
- A **margem disponível** diminui conforme novas simulações são realizadas.  
- Caso encontre erros de margem insuficiente, utilize outro CPF de teste ou reduza o valor solicitado.

---

## ⚠️ Pontos de Atenção

- Faça seus testes **sempre com valores diferentes e fotos diferentes**.  
- Nossa API valida se o **mesmo CPF** foi usado com o **mesmo valor** e **os mesmos documentos**.  
- Se isso ocorrer, o teste poderá ser rejeitado automaticamente.  

---

## 🔒 Importante

Os dados fornecidos são **fictícios e exclusivos para o ambiente de homologação**.  
Não devem ser utilizados em produção nem associados a informações reais.
