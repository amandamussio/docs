---
title: "02 - Eventos de Propostas Simuladas"
description: "Gerencie eventos de propostas simuladas para a contratação ativa"
---

Quando a simulação de propostas de crédito consignado é concluída, a Wincred envia um evento para o webhook configurado, informando o status e os detalhes da simulação.

## Você pode usar este evento para:

- Notificar o seu sistema sobre a conclusão da simulação de propostas.
- Atualizar o status da cotação no seu sistema.
- Processar as propostas simuladas para análise ou apresentação ao trabalhador.

## Casos de Uso

A Wincred disponibiliza 3 status possíveis para o evento de propostas simuladas:

| Status                       | Descrição                                                                             |
| ---------------------------- | ------------------------------------------------------------------------------------- |
| `CONCLUIDO`                  | A simulação foi concluída com sucesso e as propostas estão disponíveis.               |
| `FALHA`                      | Ocorreu um erro durante a simulação das propostas.                                    |
| `NENHUMA_SIMULACAO_APROVADA` | Nenhuma proposta foi aprovada para o trabalhador pela política de crédito da Wincred. |

---

## Header do tipo do evento no Webhook:

```http
x-event-type: v1.e-consignado.contratacao-ativa.propostas.simulacoes
```

```json

  "idCotacao": "123e4567-e89b-12d3-a456-426614174000",
  "evento": "v1.e-consignado.contratacao-ativa.propostas.simulacoes",

}
```

### Campos do Payload

| Campo                        | Tipo     | Descrição                                                                |
| ---------------------------- | -------- | ------------------------------------------------------------------------ |
| `idCotacao`                  | UUID     | Identificador único da cotação                                           |
| `status`                     | string   | Status da simulação (`CONCLUIDO`, `FALHA`, `NENHUMA_SIMULACAO_APROVADA`) |
| `propostas`                  | array    | Lista de propostas simuladas                                             |
| `idProposta`                 | UUID     | Identificador único da proposta                                          |
| `dataDeVencimento`           | datetime | Data de vencimento da primeira parcela                                   |
| `dataDaLiberacao`            | datetime | Data prevista para liberação do crédito                                  |
| `dataDeExpiracao`            | datetime | Data de expiração da proposta                                            |
| `valorDesembolsoTotal`       | float    | Valor total a ser desembolsado                                           |
| `valorSeguro`                | float    | Valor do seguro incluído na proposta                                     |
| `valorDesembolsoTrabalhador` | float    | Valor líquido a ser recebido pelo trabalhador                            |
| `valorParcela`               | float    | Valor de cada parcela                                                    |
| `numeroParcelas`             | int      | Número total de parcelas                                                 |
| `taxaJuros`                  | float    | Taxa de juros aplicada na simulação                                      |
| `comSeguro`                  | boolean  | Indica se a proposta inclui seguro                                       |
| `valorComissao`              | string   | Valor da comissão para o canal de venda                                  |
| `dataCriacao`                | datetime | Data e hora de criação do evento                                         |
