---
title: "03 - Enviar Proposta para Aprovação"
description: "Submeta a proposta escolhida pelo trabalhador para análise e aprovação"
---

<Info>
  Este é um endpoint **assíncrono**. A resposta retornará imediatamente com um
  identificador para acompanhamento do status.
</Info>

Após o trabalhador escolher uma das propostas simuladas, envie a proposta selecionada para aprovação juntamente com os dados bancários para desembolso.

## Endpoint

<ParamField path="POST" type="endpoint">
  `/api/v1/e-consignado/contratos`
</ParamField>

### Headers

| Header          | Tipo   | Obrigatório | Descrição                      |
| --------------- | ------ | ----------- | ------------------------------ |
| `Content-Type`  | string | Sim         | `application/json`             |
| `Authorization` | string | Sim         | `Bearer {seu_token_de_acesso}` |

---

### Parâmetros da Requisição

<ParamField body="idProposta" type="string" required>
  Identificador único da proposta simulada que foi escolhida pelo trabalhador
</ParamField>

<ParamField body="pessoa" type="object" required>
  Dados pessoais do trabalhador

  <Expandable title="Propriedades">
    <ParamField body="naturalidade" type="string" required>
      Cidade de nascimento do trabalhador
    </ParamField>

    <ParamField body="documento" type="object" required>
      Informações do documento de identificação

      <Expandable title="Propriedades">
        <ParamField body="numero" type="string" required>
          Número do documento (sem pontuação)
        </ParamField>

        <ParamField body="orgaoExpedidor" type="string" required>
          Órgão expedidor do documento (ex: SSP, DETRAN)
        </ParamField>

        <ParamField body="uf" type="string" required>
          UF de expedição do documento (2 caracteres)
        </ParamField>

        <ParamField body="dataDeEmissao" type="string" required>
          Data de emissão do documento no formato `YYYY-MM-DD`
        </ParamField>

        <ParamField body="tipoDocumento" type="string" required>
          Tipo do documento de identificação

          **Valores possíveis:** `RG`, `CNH`, `RNE`
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="endereco" type="object" required>
      Endereço residencial do trabalhador

      <Expandable title="Propriedades">
        <ParamField body="rua" type="string" required>
          Nome da rua, avenida, etc
        </ParamField>

        <ParamField body="numero" type="string" required>
          Número do endereço
        </ParamField>

        <ParamField body="complemento" type="string">
          Complemento do endereço (apartamento, bloco, etc)
        </ParamField>

        <ParamField body="bairro" type="string" required>
          Nome do bairro
        </ParamField>

        <ParamField body="cidade" type="string" required>
          Nome da cidade
        </ParamField>

        <ParamField body="uf" type="string" required>
          Sigla do estado (2 caracteres)
        </ParamField>

        <ParamField body="cep" type="string" required>
          CEP do endereço (apenas números)
        </ParamField>
      </Expandable>
    </ParamField>

    <ParamField body="estadoCivil" type="string" required>
      Estado civil do trabalhador

      **Valores possíveis:** `SOLTEIRO`, `CASADO`, `DIVORCIADO`, `VIUVO`, `SEPARADO`, `UNIAO_ESTAVEL`
    </ParamField>

    <ParamField body="email" type="string" required>
      Endereço de e-mail do trabalhador
    </ParamField>

    <ParamField body="telefone" type="string" required>
      Número de telefone com código do país (formato: +5511999999999)
    </ParamField>

    <ParamField body="patrimonio" type="string" required>
      Valor do patrimônio do trabalhador em formato decimal (ex: "10000.00")
    </ParamField>

  </Expandable>
</ParamField>

<ParamField body="contaBancaria" type="object" required>
  Dados bancários para desembolso do empréstimo

  <Expandable title="Propriedades">
    <ParamField body="compe" type="string" required>
       código COMPE é um número composto por três dígitos que identifica cada banco nas transações financeiras nacionais — 
       exemplos: Banco do Brasil (001), Caixa Econômica Federal (104), Itaú (341), Bradesco (237), Santander (033).
    </ParamField>

    <ParamField body="agencia" type="string" required>
      Número da agência bancária
    </ParamField>

    <ParamField body="conta" type="string" required>
      Número da conta bancária com dígito verificador (formato: 12345-6)
    </ParamField>

    <ParamField body="tipo" type="string" required>
      Tipo da conta bancária

      **Valores possíveis:** `CORRENTE`, `POUPANCA`, `SALARIO`
    </ParamField>

    <ParamField body="chavePix" type="string" required>
      Chave PIX para recebimento (e-mail, telefone, CPF ou chave aleatória)
    </ParamField>

  </Expandable>
</ParamField>

## Resposta

### Resposta de Sucesso (202 Accepted)

A requisição foi aceita e está sendo processada de forma assíncrona.

```json
{
  "idProposta": "123e4567-e89b-12d3-a456-426614174000"
}
```

### Resposta de Erro (422 Unprocessable Entity)
```json
{
  "erro": "Dados inválidos"
}
```

### Resposta de Erro (401 Unauthorized)
```json
{
  "erro": "Token de acesso inválido ou expirado"
}
```

### Códigos de Status

| Código | Descrição                            |
| ------ | ------------------------------------ |
| `202`  | Requisição aceita e em processamento |
| `401`  | Não autorizado - token inválido      |
| `422`  | Erro de validação dos dados          |
| `500`  | Erro interno do servidor             |
