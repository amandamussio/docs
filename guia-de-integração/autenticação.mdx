## Guia de Integração via API

Esta página fornece uma visão geral dos ambientes de homologação e produção para nossas APIs. Aqui, você encontrará as URLs específicas para cada ambiente que permitem o acesso seguro e adequado às funcionalidades das nossas APIs, seja para testes durante a fase de desenvolvimento ou para operações em escala real após o lançamento.

Cada URL está categorizada por sua finalidade específica, facilitando a integração e o uso correto das APIs.
